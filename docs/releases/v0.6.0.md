# Beadscope v0.6.0 — Made for phones, with a project rename

Beadscope now works on a phone, and a project can be renamed from the project switcher.

## New

- **Rename a project.** The project switcher has a pencil beside each project (not Demo).
  It opens a dialog; a blank name is rejected. The new name shows in the switcher, the
  project list and the browser tab title without a reload, and the project id and URL do
  not change.
- **A phone layout.** Every view fits a phone: Board columns and Focus lanes fold into
  sections, List rows are readable, the bead drawer and New bead dialog fit the screen,
  and Insights, Needs You, Epics, Settings and Publish no longer scroll sideways. Tap
  targets are 44px and form fields are 16px, so iOS Safari does not zoom. The Graph view
  is desktop only; a phone falls back to the default view.
- **Agent identities.** Settings lists agents, the assignee picker offers the ones that
  are switched on (with icons), and Focus has an Agent filter.
- **`beadscope add [path]`** registers a repository with the running server.
- **The theme button cycles System, Light and Dark.**

## Improvements

- One type system (five sizes, three weights) on every page.
- Shared buttons, fields, selects, page header and chips replace hand-written controls.
- A quality gate walks every screen state in the light and dark theme and fails on
  overflow, unnamed controls, low contrast and console errors.

## Fixes

- The bead drawer no longer slides sideways with long ids.
- Loading headers say Loading, and the Throughput chart draws.
- The launcher's Remove from list is visible and 44px on a phone.
- bd's per-user `~/.beads` folder is no longer treated as a project.
- `?bead=` stays in the URL when Next's router rewrites it.

## Update

```sh
npm install -g beadscope        # or: brew upgrade beadscope
beadscope stop && beadscope start
```
